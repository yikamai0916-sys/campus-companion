# 操作反馈与异常体验检查

检查日期：2026-10-22。

本轮围绕登录注册、账号安全、Outlook 连接、列表加载、个人资料、待办、小组与会议的输入校验、失败提示和恢复入口检查。代码检查覆盖主要操作入口；真实浏览器测试使用模拟接口，不读取真实学生邮件，不创建真实账号。不能据此宣称所有设备、第三方故障和并发组合均已验证。

## 已修复与验收标准

| 场景 | 原问题 | 现在的行为与验收标准 |
|---|---|---|
| 注册、重置和修改密码 | 无确认密码；输入无法查看 | 提供确认密码；两次不一致阻止提交。密码和密保答案有独立显示按钮，支持键盘、可读标签和按下状态；重置表单后恢复隐藏 |
| 不完整邮箱，例如 `kaiqiou@outlook` | 浏览器原生邮箱校验允许通过，整页跳转显示 JSON | 前端要求完整域名，保留输入并提示；服务端校验继续保留，绕过前端仍拒绝 |
| Outlook 启动授权 | 直接导航至 API，失败时离开产品界面 | 表单先请求 JSON；仅成功后跳转微软。失败留在原表单，可修改重试 |
| Outlook 回调失败、取消授权 | JSON 错误页或缺乏下一步 | 返回设置并显示可重试提示；会话失效返回登录。回跳只携带固定错误类别，不携带微软错误全文和凭据 |
| 断网、本地服务停止、请求超时 | `Failed to fetch`、无结束时间 | 显示网络或超时提示；写操作说明结果未确认，不自动重发；默认请求等待上限 30 秒 |
| 密码校验失败 | 所有 401 都被当作会话失效 | 只有 `SESSION_EXPIRED` 才返回登录；错误的当前密码留在账号安全表单 |
| 登录失效 | 弹窗可能挡住登录页 | 关闭顶层弹窗并显示登录失效提示，不显示过期会话中的私有页面 |
| 首次载入失败 | 静默显示登录或空白区域 | 显示连接失败原因；列表错误使用显式重试入口 |
| 待办、邮件、小组、日报、设置加载失败 | 加载状态不结束，错误放在远离操作的位置 | 对应区域显示错误和重试按钮；追加邮件失败保留已加载记录并恢复按钮 |
| 邮件建议加载失败 | 错误被吞掉 | 建议区域独立显示失败与重试，邮件列表仍可使用 |
| 邮件搜索请求交错 | 旧请求可能覆盖新搜索结果 | 使用请求序号丢弃过时结果 |
| 待办勾选保存后列表刷新失败 | 误回滚为未完成，让用户以为没保存 | 明确显示保存已完成但刷新失败，重试只重新加载列表 |
| 邮件详情失败 | 错误可能写入隐藏的中文面板 | 切换到可见错误面板并提供重试 |
| 同步失败 | 按钮仍写“正在同步” | 恢复“立即同步”和可点击状态 |
| 修改密码、密保、找回问题 | 部分操作可重复提交 | 请求期间禁用对应按钮，结束后恢复；表单旁保留错误 |
| 头像过大或文件读取失败 | 缺少及时提示 | 超过 2 MB 阻止读取；文件读取失败在原表单显示提示 |
| 通知未配置 | 按钮禁用但没有解释 | 明确说明服务尚未配置，提示先在站内查看待办 |
| 退出请求失败 | 页面看起来退出，但服务端会话仍有效 | 显示失败，只有退出成功后才跳转 |
| 无成员可选择 | 操作无反应 | 提示先选择成员 |
| 非预期服务端异常 | 数据库或运行时诊断直接暴露 | 技术异常返回通用错误与 500；业务校验继续保留具体原因 |

## 检查中保留的现有行为

- 待办编辑、会议区间、候选分工和成员操作仍由服务端验证权限及业务条件。
- 小组邀请、分工审核、投票、确认和删除已有失败处理；公共请求层现在也会在当前表单保留错误。
- 删除邮件摘要明确说明不会删除 Outlook 原邮件；删除待办和变更成员保留确认步骤。
- 邮件解析结果仍需人工确认，避免把错误提取的日期直接变成待办。
- 写操作断网后不自动重试，避免重复建任务、会议或邀请。

## 验证记录

1. `pnpm test`：77 项通过，包括 OAuth 返回流程、会话隔离、表单网络错误、超时、服务器异常脱敏、原有会议及分工流程。

4. 人工检查手机注册页截图：确认密码和显示按钮可见，无横向溢出。

浏览器脚本需要本地服务及 Playwright。可用 `CAMPUS_PLAYWRIGHT` 指向已有 Playwright 包路径，再运行 `node test/ux.browser.mjs`。此工具不加入生产依赖。接口模拟与真实 Microsoft 授权成功率属于不同验收层。

## 后续明确未包含的产品工作

- 历史邮件导入：仍仅按现有同步范围处理，需要另外提供 7／30／90 天选择、扫描/跳过原因和分页进度。
- 本地定时任务不会自动运行；日报和自动同步需部署后的调度或明确的本地调度测试，不能仅凭页面文案视为已启用。
- 跨设备草稿恢复及写操作幂等键尚未实现；当前网络提示要求先确认结果后重试。
- 注册邮箱的格式校验不等于邮箱所有权验证，后续应单独设计验证邮件与账号找回流程。
- 用户给出的小红书参考链接无法取得正文，本轮未把未知技能内容当作已阅读或已执行。
