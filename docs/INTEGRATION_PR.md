# 整合学生协作与邮件阅读，修复成员退出、异常恢复及缓存生命周期

草稿 [PR #7](https://github.com/yikamai0916-sys/campus-companion/pull/7)。目标：`codex/collaboration-review-upgrade`；来源：`codex/integration-stability`。

学生从日报或邮件进入阅读器后，现在可以回到原来源；阅读失败显示可见提示，会话失效会关闭阅读层。资料保存直接使用当前昵称。小组读取失败保留输入并提供就地重试。

本分支整合本地反馈修复、协作分支 `9deb2aa` 和邮件分支 `3c29b49`，保留确认密码、OAuth 恢复、超时、会话分类和新版日报。有效译文先于服务冷却读取；缓存新增最长 7 天期限、账户/邮件关联和删除写回保护，删除本地邮件保留独立的已确认任务。

验证：107 项单元/数据库测试通过；应用语法检查通过；Chrome 合成接口反馈测试及三个真实本地账号的协作测试通过。三账号测试关闭外部连接与模型，覆盖邀请、审核、接受/拒绝、任务完成、会议投票、确认、取消/改期、成员移除及账号切换。详细步骤、截图与覆盖限制见 `docs/INTEGRATION_ACCEPTANCE_2026-10-23.md`。

需要应用本地验证过的迁移 `0015_mail_cache_lifecycle.sql`。生产迁移与部署未执行；旧 KV 全文译文不再读取，按迁移登记的最长 7 天期限分批清理，首次打开可能重新生成。回滚应用不恢复已清理缓存，也不能直接撤销数据库迁移。

本 PR 不替团队决定是否替代 #6，不关闭原有串联 PR。历史导入、导航重组、课表与聊天不属于这次整合。
