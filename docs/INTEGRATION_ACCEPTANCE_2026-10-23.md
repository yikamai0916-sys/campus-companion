## 数据与缓存操作规则

- 新迁移 `0015_mail_cache_lifecycle.sql` 为新增表、字段、索引和触发器；不删除独立任务或整张 KV 表。本地个人预览库已经应用；未运行任何远程迁移。
- 新全文译文与简报缓存关联账户、邮件和实例版本。`MAIL_CACHE_DAYS` 默认 7，限制在 1–7 天；读取不续期。到期后不返回；调度每批清理最多 100 条。未运行调度的本地环境不会自动物理清理，不能把“不可读”写成“已从磁盘清除”。
- 旧 `fulltrans:*` 键除共享冷却标记外进入过期清单，不再作为可读译文使用；迁移后最长 7 天进入分批清理。升级后第一次打开旧邮件可能重新生成译文。已核查历史版本有 v1、v3 和 v6；删除邮件按账户、邮件哈希精确清理 v1–v6 键及该邮件的简报/重试键，不按模糊账户前缀删除无关记录。
- 删除本地邮件时清理全文译文、简报、结构化本地化与候选；不删除 Outlook 原邮件。已确认任务及其备注/证据独立保留，可在待办单独删除，确认对话框已说明。
- 断开 Outlook 删除本地授权记录并停止后续连接使用；保留本地邮件和任务，不等同于删除所有本地数据，也不等同于撤销 Microsoft 账户侧全部授权。
- 缓存写回必须匹配请求开始时的邮件实例；删除后重新导入同一个外部 ID 也不能接收旧写回。邮件分析字段变更会更新实例版本并清理旧缓存。
