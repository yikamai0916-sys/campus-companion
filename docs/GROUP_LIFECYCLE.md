# 小组退出与解散

更新：2026-10-24。替代原有“先取消会议、处理完分工才能退出”的限制。

## 成员退出或组长移除成员

- 普通成员可随时退出；组长可随时移除普通成员，无需预先处理会议或分工。组长本人可转让职责后退出，或直接解散小组。
- 未完成分工标记为 declined，停止该成员相关待发送提醒，留在小组看板供组长重新安排。尚未审核候选中的建议负责人清空，防止再分配给已退出人员。
- 该成员未完成的会议待办移除。已完成个人分工转为独立个人记录保留。
- 未确认会议退回时间收集，保留剩余成员已提交的可用时间，清空旧投票/候选选项。更新 revision，拒绝旧版本操作。
- 已确认会议对剩余成员继续有效；离开者从参与名单、可用时间和投票中移除。其他成员的会议待办与提醒保留。
- 退出后立即失去小组和会议的访问权限，小组公告记录成员变化。

## 组长解散

任何会议阶段、任何分工进度均可由当前组长解散，包括只有组长一人的小组。普通成员和非成员不能解散。

确认后以数据库事务删除小组、成员关系、邀请、候选、公告、会议、可用时间和投票；取消小组任务的待发送提醒，移除未完成小组待办。已完成个人分工脱离小组保留。其他小组、私人邮件和私人待办不受影响。确认对话框明确说明清理范围及无法撤销。

无需新增迁移；使用现有状态字段和表。
